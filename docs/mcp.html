MCP access model

Agent access without weakening the registry.

OpenWave Identity MCP exposes support-safe Identity tools for agents while keeping the bank-vouched trust model intact. Agents call official Identity APIs with the same bank, customer, or registry permissions as the portal.

Default posture

No direct database access. No raw secrets in prompts. No broad customer lookup without an authenticated role.

OPENWAVE_IDENTITY_BASE_URL=https://identity.neptune.ly/v1
OPENWAVE_MCP_ENABLE_MUTATIONS=false

For registry owners

Review registry health, bank readiness, portal access posture, and audit-safe operational summaries.

For banks

Inspect only customers, aliases, linked accounts, and login approval work owned by the authenticated bank.

For customers

Show linked NPT aliases, bank routes, and security posture through the customer portal session.

For developers

Resolve public aliases, inspect bank directory metadata, and build fintech tools against clear role boundaries.
