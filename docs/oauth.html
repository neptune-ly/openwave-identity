OAuth access with operator control.

OpenWave Identity is the OAuth/OIDC issuer for Astro, Remote MCP, banks, merchants, and future fintech apps. Tokens are scoped, revocable, environment-aware, and protected by kill switches.

Client registry

Register confidential, public, and agent clients with allowed scopes, redirect URIs, owner type, and live/sandbox access.

Kill switches

Turn off OAuth globally, MCP globally, write tools, live access, or a specific owner type without deleting clients.

Revocation

Suspend clients, revoke client tokens, revoke user grants, and rotate secrets from the registry admin surface.

Resource servers

Astro and Remote MCP validate tokens by introspection so revocation and kill-switch changes take effect quickly.

EndpointPurpose
POST /v1/oauth/tokenIssue client-credentials or refresh tokens.
POST /v1/oauth/introspectValidate access tokens and expose scoped claims to resource servers.
POST /v1/oauth/revokeRevoke one access or refresh token.
